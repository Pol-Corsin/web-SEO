# web-SEO
Practica pagina estatica SEO


# ENUN

En grups de 2 o 3, creeu una web amb una pàgina principal i 3 o 4 secundàries sobre un tema que us interessi seguint els criteris de SEO per aconseguir un bon posicionament en els cercadors: estructura de la pàgina, URLs, etiquetes, paraules clau, usabilitat, accessibilitat i arxius robots.txt, sitemap.xml i schema.org.
